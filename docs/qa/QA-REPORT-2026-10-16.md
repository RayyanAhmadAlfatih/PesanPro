## LAPIS 3 — Audit Statis Jalur Kritis (4 auditor paralel) — **PASS dengan temuan**

Cakupan: ~90 route API (26 handler messaging/media/autoreply/broadcast; 22 handler
webhook/session/scheduler/legacy-messages/internal; 21 handler admin/billing/users/
settings/monitor; 16 handler auth/keys/notifications/health) + service layer +
`proxy.ts` + `api-auth.ts`.

**Hasil bersih (tidak ditemukan pelanggaran):**
- Auth: **100% handler** memanggil `getAuthenticatedUser` → 401 tanpa auth. Edge
  (`proxy.ts:56-128`) menegakkan API key + scope + rate limit + kuota bulanan
  sebelum route jalan. Session auth re-validasi status ACTIVE + sessionVersion.
- Tenant isolation: **tidak ada IDOR**. Setiap query Prisma di-scope userId/tenantId
  (`canAccessSession`/`isSessionOwner` sebelum akses; SUPERADMIN tidak bypass
  ownership — `api-auth.ts:151-168`). Route berbasis ID selalu kombinasikan
  tenantId di where-clause → cross-tenant ID → 404.
- Password reset: token 32 byte acak, disimpan SHA-256, TTL 30 menit, single-use
  (compare-and-set di transaksi), token lama dihapus, **sessionVersion di-increment**
  (semua sesi lama mati).
- OTP: HMAC-SHA256 + domain separation, TTL 10 menit, 3 percobaan, cooldown 60s,
  limit 3/email/15mnt + 10/IP/jam, anti-enumerasi identik.
- API key: secret tampil sekali, SHA-256 hash, revoke/rotate serializable, scope
  wajib eksplisit (commit `a57e26c`), IP allowlist divalidasi & ditegakkan.
- Webhook signature: HMAC timestamped + rotasi secret (previous 24h), secret
  terenkripsi AES-256-GCM, log redacted.
- Billing: nominal dikirim dari harga plan server-side (tidak bisa diubah klien),
  approval idempoten (Serializable), `startsAt` dari server.
- Validasi input: zod `.strict()` di hampir semua boundary mutasi; regex
  anti-ReDoS; CSV/spintax terbatas; upload magic-byte + size cap.
- Tidak ada secret hardcoded; error generik (satu pengecualian → **T-1**).

**Temuan audit → daftar issue di `GITHUB-ISSUES-2026-10-16.md` (T-1 … T-15).**
